BRING YOUR OWN LOCAL MODEL

Replay it. Then make it yours.

Launch this optional Python app with STRATA_BASE_URL pointing at your Strata server. The foundation experiments use the logprobs branch. Native sampler inspection additionally requires ordered-host-v1 from the samplers branch. Keep API keys on the Python server.

Windows and Linux connection examples
Windows PowerShell
$env:STRATA_BASE_URL = 'http://127.0.0.1:8080'
$env:STRATA_API_KEY = 'your-key-if-configured'
python -m examples.control_lab --port 8876

Ubuntu
export STRATA_BASE_URL=http://127.0.0.1:8080
export STRATA_API_KEY=your-key-if-configured
python -m examples.control_lab --port 8876

A first recorded run needs none of those connection variables. Open the app at 127.0.0.1:8876. For a LAN server, substitute its authenticated address.
